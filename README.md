# Faça seu Pinpoint! · CRIACOM Microjogos Vol. 13

Planejador gamificado da VL4 ("Aplique um pinpoint na sua vida") da disciplina 6PAC099 (UEL, 2026/2).
Observar · intervir · observar: pinpoint, medida e meta, observação inicial, intervenção, nova observação,
registro por oportunidade, gráfico por etapa, economia de fichas, conquistas e mural com compartilhamento opcional.

## Publicação
Envie todo o conteúdo desta pasta para a raiz do repositório e ative o GitHub Pages
(Settings → Pages → branch `main`, pasta `/root`).

## Estrutura
- `index.html`: o jogo (HTML, CSS e JS num arquivo só)
- `img/`: capa e poses do Boatacon
- `img/capa-vol13.png`: capa em alta resolução (1024×768) para divulgação

## Exemplo do professor
Os textos e registros do exemplo ficam no bloco `PROF`, no início do `<script>` do `index.html`.

Os dados dos alunos ficam apenas no navegador de cada um (localStorage); nada é enviado a servidor.
